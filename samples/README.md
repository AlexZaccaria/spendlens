# Sample inputs

Deliberately irregular, multilingual documents for trying the AI import. They are generated by
`tools/make-samples.ts` (`npm run samples`), byte-for-byte reproducible, and dated October 2026.
Drop any of them — or all at once — on the **Import** page.

| File | Language | Format | What makes it irregular |
|------|----------|--------|-------------------------|
| `it-intesa-estratto-conto-2026-10.csv` | Italian | CSV, windows-1252, `;` | Preamble lines (holder, masked IBAN, period), `dd/mm/yyyy`, comma decimals, separate *Dare*/*Avere* columns, opening/closing balance rows, a quoted multi-line description |
| `de-sparkasse-umsaetze-2026-10.csv` | German | CSV-CAMT, ISO-8859-1, quoted `;` | `dd.mm.yy` dates, `-12,50` amounts, *Auftraggeber/Empfänger* + *Verwendungszweck* columns, umlauts in a legacy encoding |
| `en-revolut-statement-2026-10.csv` | English | CSV, UTF-8 | ISO datetimes, GBP/USD/EUR mixed, a PENDING and a REVERTED row, an exchange pair, a top-up (transfer) and a fee column |
| `en-wise-statement-2026-10.csv` | English | Wise CSV export, UTF-8, CRLF | Two balances (EUR then GBP) concatenated with their own running balances, a EUR→GBP conversion pair, fees in their own column, a cancelled card hold, a refund, a split-dinner transfer with a payment reference |
| `fr-releve-carte-2026-10.ofx` | French | OFX 1.x SGML | Unclosed SGML tags, card spending printed per OFX conventions, French merchant names |
| `es-gastos-octubre.xlsx` | Spanish | Excel workbook | Title row, merged-looking headers, a blank row, a *TOTAL* row, user categories that don't match ours, a second sheet of notes |
| `it-note-spese.txt` | Italian + English | Free text | Relative dates (*ieri*, *l'altro ieri*, *yesterday*), `23,50` / `€38.40` / `~40 euro`, a shared bill (*diviso in due*) |
| `it-bolletta-enel-2026-10.pdf` | Italian | PDF (text layer) | A utility bill: billing period, consumption, total to pay and a due date that is not the transaction date |
| `en-receipt-tesco.png` | English | Receipt photo | A supermarket receipt as an image: line items, VAT, card payment — read with vision |
| `it-scontrino-esselunga-2026-10.png` | Italian | Receipt photo | One supermarket ticket mixing food, nappies and baby food, laundry detergent and hand sanitiser, a per-line discount (`SCONTO 20%`) and a loyalty discount on the total: each line is extracted as its own item and category |

The import pipeline sends PDFs and images to the model as they are when the provider reads them
natively (Claude, OpenAI); OpenAI-compatible servers get the PDF text instead.
